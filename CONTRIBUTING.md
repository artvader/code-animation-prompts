# Submission and supplementary image specifications

Feel free to add reference images to existing styles, fix indexes, or provide runnable code animations. Confirm the number before submitting to avoid duplicate pictures; there is no need to rewrite the original style prompts.

## Reference picture

- It is recommended to use 1920×1080, 16:9, and the file name should be consistent with the corresponding prompt word, such as `K1_flat-vector.jpg`. The default preview gives priority to pure images, and puts the name, feature description and color palette in additional descriptions to ensure that the thumbnails can still identify the painting style.
- One picture focuses on one painting style; try to use the same scene when comparing multiple styles. The existing K1–K3 are the first community description cards to be retained and are not required as formats.
- For code-generated images, please try to attach SVG, HTML or a generation script, describing the rendering method, size, font and dependencies. If it is only JPG, please mark it truthfully and do not claim that editable source code has been provided.
- Indicate the author, source and applicable license or sharing agreement; for original submissions, please make it clear whether you agree to the repository's free use, modification and sharing agreement. Third-party works retain their respective authorizations and signatures. Do not claim uncredited material as original or uniformly credit it as MIT.

## Sources and Indexes

1. The original `docs/source-manifest.json` is a fixed baseline, please do not overwrite the hash in it to make the verification pass.
2. Register new files or intended modifications in `skills/code-animation-prompts/references/library-changes.json`: current SHA-256, reason, contribution record; when modifying the original file, you must also retain `original_sha256` that is consistent with the baseline.
3. Add the author and source to the skill `references/attribution.md` so that the installed copy will also retain the signature. The original package description and license remain in their original text.
4. Update the picker and `stats.json`, then run `python scripts/build_catalog.py`. Synchronize README, SKILL and affected display images, not just modify the generation script.

## Check before submission

```bash
python scripts/validate_repo.py
python skills/code-animation-prompts/scripts/styles.py search ink --limit 3
python skills/code-animation-prompts/scripts/styles.py show K1
```

Check that the newly added images can be loaded, enlarged, and filtered in the picker; attach a preview and list the verification results in the PR.

The README image is generated by `scripts/build_visuals.py`, and the quantity automatically reads the directory index. After installing Playwright you can run:

```bash
python scripts/build_visuals.py --browser-channel chrome --skip-video
```

This command uses native Chrome, updates the PNG and leaves the GIF unchanged. Use Playwright's Chromium when not specifying a browser channel; remove `--skip-video` and make sure FFmpeg is available when rebuilding the GIF.
