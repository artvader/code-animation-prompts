# M38 A shape changes to the bottom

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic style · Structure and lens type (used to string together different styles)
- What it looks like: The same shape keeps changing: button, loading circle, player, slider, switch... Every time it changes, the mouse actually clicks.
- Suitable for: Paragraphs that list many examples at once, such as "organizing tables, writing weekly reports, batch editing of files, and doing self-media".

## Style prompt words

A shape is not cut from beginning to end, and turns into [Example 1, Example 2, Example 3...], changing the size, rounded corners and color. Each change is triggered by an actual mouse click or drag. Use springs here and there, a little bit of rebound at most. The camera zooms in, allowing each state to fill the screen. The last frame is the same as the first frame.
