# M13 Hand-drawn freeze-frame, first person

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic Style · Emotion and atmosphere (feeling lines are most commonly used)
- What it looks like: A hand-drawn, shaky stop-motion animation, where the things in the picture speak for themselves.
- Suitable for: Let something speak for you. For example, let "that gadget that catches announcements" introduce itself.

## Style prompt words

Make a hand-drawn stop-motion animation. You are [the thing], introducing yourself to the audience in the first person.
