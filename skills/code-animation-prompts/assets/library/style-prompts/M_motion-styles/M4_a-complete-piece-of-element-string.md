# M4 A full piece of element string

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic style · Structure and lens type (used to string together different styles)
- What it looks like: A small thing (an orange dot, a white ball) appears throughout all scenes: it becomes a switch, then a dot on a letter, then a curve, then a shape, and finally back to the end.
- Suitable for: "line" when mixing styles. For example, you can use a small dot to represent "announcement" and "idea" from beginning to end.

## Style prompt words

A [color] dot connects each scene: [what it is in scene 1], then to [what it is in scene 2]... and finally back to the ending card. The dot cannot teleport, it can only move continuously. The action is crisp and clean, the spring rebound is very small, and there is no gap. No need for video footage, gradients, glows, particle explosions, or random transitions. The last frame is the same as the first frame and can be looped.
