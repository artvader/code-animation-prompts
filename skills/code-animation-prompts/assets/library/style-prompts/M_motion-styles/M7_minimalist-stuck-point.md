# M7 minimalist stuck point

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic Style · Rhythm and Quick Cut
- What it looks like: A shot that only tells one thing, lots of white space, only one accent color, and every cut is a retake.
- Suitable for: fast-paced paragraphs, such as "The forms you need to organize every day, the weekly reports you need to write every week...".

## Style prompt words

Advanced minimalism. A shot only tells one thing, with a lot of white space, only one accent color, sans serif fonts with tight spacing, text showing through a mask, and a steady shot. Every cut is on the beat, and every interface action is on the beat. There should be no periods in the words on the screen. No shockwaves, particles, RGB separation, jitter, halo, neon, flicker, bouncy easing. Only use commercially available music and sound effects.
