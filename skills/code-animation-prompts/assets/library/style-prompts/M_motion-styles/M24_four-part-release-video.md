# M24 four-part launch video

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic Style · Explanation
- What it looks like: general environment, pain points, solutions, benefits, four paragraphs, and finally the logo animation ends.
- Suitable for: paragraphs introducing a new tool or a skill.

## Style prompt words

You are a senior motion designer. Make a [30] second video, 4 to 5 scenes: why this matter is important now, everyone’s current troubles, how [the tool] solves it, and the benefits of using it in the future. Text appears word by word, using spring physics to make movements. Elements enter the scene according to the beat, and do not appear suddenly. Each element appears with a very light sound effect, and is quiet at other times. Finally, use the logo animation and add a sentence to finish. After rendering it yourself, check it frame by frame. If there are overlaps, cropping, or things that are too rushed, please correct them and send them to me.
