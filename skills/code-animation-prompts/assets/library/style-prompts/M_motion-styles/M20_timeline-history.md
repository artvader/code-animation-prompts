# M20 Timeline/History

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic Style · Explanation
- What it looks like: A timeline goes forward, and one thing pops up at each node.
- Suitable for: "How did I get through these three months", "How did AI develop to what it is today".

## Style prompt words

Make a line animation for a period of time and talk about several key nodes of [from when to when]: [Node 1, Node 2, Node 3]. The timeline advances from left to right. At each node, the screen zooms in to talk about the incident, then shrinks back and continues.
