# M5 One shot to the end

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic style · Structure and lens type (used to string together different styles)
- What it looks like: There are no cuts from beginning to end, each scene is "grown" from the previous scene.
- Suitable for: paragraphs that talk about changes, such as "I used to push it by myself, but now I sit in it and it walks by itself." One screen changes to another.

## Style prompt words

One shot to the end. Each scene emerges from the last: text rises from a line, buttons expand into pages, a color fills the screen and cuts to the next paragraph. No fades, no blurs, no hard cuts. Only one slow motion is performed for each scene shot.
