# M23 Five Acts of Explanation (Universal Explanation Template)

Output language: Use English for all subtitles, narration, titles, labels, signs, and other readable text unless the user explicitly requests another language.

- Category: M Dynamic Style · Explanation
- What it looks like: Five pictures tell one thing.
- Suitable for: the skeleton of an issue of science popularization, or a paragraph about a tool in the experience line.

## Style prompt words

You are a senior motion designer. Use an HTML page to make a [30] second explanation animation, divided into 5 scenes: 1) problems encountered by the audience; 2) what [thing] is; 3) how to use it, 3 steps; 4) a real example; 5) end card with [channel name]. The words should be big and bold, the transitions should be smooth, and use our color matching.
